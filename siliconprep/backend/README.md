# SiliconPrep backend

FastAPI + PostgreSQL API for the SiliconPrep frontend. The judge (code
execution) is currently **mocked** — every submission is reported as a pass
without actually compiling or simulating anything. See the comment in
`app/routers/submissions.py` for where to plug in a real simulator.

## 1. Install PostgreSQL and create a database

macOS: `brew install postgresql@16 && brew services start postgresql@16`
Windows/Linux: use the [official installer](https://www.postgresql.org/download/),
or run Postgres in Docker if you already have it:
`docker run --name siliconprep-db -e POSTGRES_PASSWORD=postgres -p 5432:5432 -d postgres`

Then create the database:
```
psql -U postgres -c "CREATE DATABASE siliconprep;"
```

## 2. Set up the Python environment

```
cd backend
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 3. Configure the connection string

```
cp .env.example .env
```
Edit `.env` if your username/password/port differ from the default
(`postgres` / `postgres` / `5432`).

## 4. Create the tables and seed data

```
python seed.py
```
This creates all tables (if missing) and loads the 24-problem catalogue.
Safe to re-run — it wipes and re-inserts the seeded tables each time.

## 5. Run the API

```
uvicorn app.main:app --reload
```
Runs at `http://127.0.0.1:8000`. Interactive API docs (auto-generated by
FastAPI) are at `http://127.0.0.1:8000/docs` — useful for testing endpoints
without the frontend.

## Endpoints

| Method | Path                    | Description                          |
|--------|-------------------------|---------------------------------------|
| GET    | `/api/problems`         | List problems (filter: `search`, `language`, `topic`, `difficulty`) |
| GET    | `/api/problems/{slug}`  | Single problem + starter code         |
| GET    | `/api/topics`           | Distinct topic list                   |
| POST   | `/api/submissions`      | Run/submit code (mocked judge result) |
| GET    | `/api/health`           | Health check                          |
